# Install `zotero`

Use this reference only when `zotero --version` is unavailable.

The published package requires Node.js 24 or later:

```sh
npm install -g @jfomhover/zotero-cli
```

Verify the executable:

```sh
zotero --version
```

After installation, return to the main skill instructions. Configure `ZOTERO_KEY` through the process environment or the user's approved secret-management mechanism; do not place it in command arguments or commit it to a file.
